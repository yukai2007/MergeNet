ImageNet 大规模长训验证

CIFAR-100 上已经形成可追溯的多随机种子精度结果、明确的压缩—精度取舍，以及接近 DeiT 的最新推理吞吐。 当前正确结论是“可交付做规模化验证”，不是“ImageNet 已经验证”或“生产效率已闭环”。

交付结论 优先交付 4+8 / λ=4 / window=32 压缩版；先通过完整 preflight，再从头进行 ImageNet 新训练。历史 canonical 主路径是 LocalBlock（unbiased attention）+ DTEMMergeOnly，本次 biased-attention 修复属于兼容路径加固，不改变主结果的前向语义。新训练的原因是更换到 ImageNet-1K 数据、类别空间与训练尺度，而不是历史 CIFAR 主路径被该兼容缺陷污染。

主训练协议

CIFAR-100、从头训练 200 epochs、输入 224、patch size 8（784 patch tokens）、global batch 200、AdamW、 warmup 20 + cosine；Mixup / CutMix / RandAugment / random erasing；EMA 0.9998。logit KD 使用同一 DeiT teacher， 权重 1、温度 2。MergeNet 共用 DTEM window 8、feature dim 64、source_trace=center、 cls_global=true、metric grad scale 0.1、soft top-k auxiliary 0.05。

辅助控制与结论边界

无 KD 的单 seed 控制中，DeiT 为 66.53，MergeNet 6+6 / λ=4 / w16 为 69.24（+2.71 pp），支持收益不只来自教师； 但该控制同样只有一个 seed。ToMe 对照与历史 resize / warm-start 采用不同协议，只能作为方向性或负面机制证据， 不并入主表。这里的“压缩率”指进入 latent encoder 的 patch token 数减少，不等于端到端 FLOPs 同比例下降； cross-attention 仍包含 K×N 计算。另需注意：dtem_window_size=8 是 flattened row-major 序列上的 ±8 邻域， 不是 2D 8×8 空间窗；source_trace=center 只用于 center-of-mass 排序，不提供 dense source-aware cross-attention bias。 二者都不应在 ImageNet 交付中被静默改成新的算法变体。

Clean efficiency

最新 fast path 微基准

synthetic · FP16 · batch 50

4 张 A100-SXM4-80GB 分别运行；PyTorch 2.6.0 + CUDA 12.4；每项 warmup 20、计时 100 steps。 训练项包含 student forward + CE + backward + AdamW；不含 dataloader、数据增强和教师网络。 吞吐为四卡独立测量的均值 ± 样本标准差，范围为最小–最大；显存为 peak allocated 均值。

Checkpoint-compatible inference

fast 推理已做全测试集 replay

  • λ=4 / w32 seed 42：generic 70.91，fast 70.91，预测一致率 1.0000。
  • λ=2 seeds 42 / 43 / 44：Top-1 最大差 0.01 pp，预测一致率 0.9998–1.0000。
  • 因此，历史 checkpoint 可用于 fast inference 的精度兼容性说明。

replay 是独立全测试集重评估，四舍五入后可与训练期 summary 相差 0.01–0.02 pp；其用途是同一 replay 内的 generic / fast 配对比较。

Training not jointly validated

fast 训练仍需新实验

  • 主准确率训练：random_per_sample。
  • fast 微基准：alternating_per_layer_fast。
  • 旧、与准确率路径一致的 generic 训练测得 λ=4 为 0.741× DeiT、8.50 GiB（1.26×）。

未提供经审计的 FLOPs，也没有 batch=1 在线延迟；上表 batch step time 不能替代单样本延迟。参数量方面，λ=4 / λ=2 分别比 DeiT 增加约 4.6% / 4.8%。表中参数量来自 CIFAR-100 head 的 microbench；交付包换成 1000 类 ImageNet head 后分别为 DeiT 22,055,272、λ=4 23,047,784、λ=2 23,097,064，二者差异来自分类头类别数。

biased-attention 修复与 canonical 主路径的关系

!
修复是必要的兼容路径 hardening，但不是历史 CIFAR 主结果的语义变更。 交付版已在 biased_local_attention 中把 DTEM 的 BHND 输入显式转换为 FlashAttention 需要的 BNHD， 并在 DTEMAttention.forward 去掉 caller 侧对 q 的预缩放，使 softmax_scale = 1 / sqrt(head_dim) 只生效一次。交付测试已覆盖 BHND / BNHD、N>H / N<H、 forward / backward parity、局部性和 DTEM caller；canonical CUDA forward / backward 与有限梯度 smoke 也已通过。 历史主模型实际走 LocalBlock 的 unbiased attention 与 DTEMMergeOnly，因此 CIFAR 结果仍可作为同一 canonical 架构的 scale-up 证据。 ImageNet 必须 fresh train，是因为这是尚未做过的新数据集 / 新类别空间 / 新规模验证，而不是为了“修复后重现”历史 CIFAR 数值。
本报告排除的实验

不纳入主结论：早期未完成 / 短跑目录；错误 ImageNet normalization 的 grouping 评估；smoke256、batch16 preliminary、 zero-train-step preflight；兼容 DTEMAttention 路径在 BHND layout 修正前的 implementation-check-only 记录；旧 800e warm-start 中断结果；不同协议的历史 resize fine-tune； post-hoc 4+8 ToMe 机制负例；以及首轮包含慢 DeiT 卡异常的 2026-08-02 efficiency 数据。

开跑前检查清单

  • 确认数据为 ImageNet-1K、1000 类，train / val 目录与样本数正确；不要沿用 CIFAR normalization。
  • 若启用 logit KD，必须使用匹配 ImageNet-1K 类别空间的 teacher；CIFAR teacher checkpoint 不可复用。
  • 确认 global batch、学习率缩放、gradient accumulation、AMP、EMA 与 resume 行为。
  • 先比较 DeiT 与 MergeNet 的单步 loss / gradient、50–200 step 吞吐和 peak memory，再进入长训。
  • 保存配置、代码 commit / dirty diff、环境版本、每 epoch 指标、best / last checkpoint 与 sha256。
  • 报告 ImageNet 结果时，将训练吞吐、验证吞吐、显存、参数量与 FLOPs 分开；不要以 latent token 压缩率替代 FLOPs。
